# Student_Performance_Analytics_System

## Overview
A MySQL-based Advanced Database Management System project designed to analyze student academic performance, attendance, grades, and rankings.

## Features
- Student performance analysis
- Automatic grade calculation
- Student ranking using window functions
- At-risk student identification
- Department-wise performance reports
- Marks validation using triggers

## Technologies Used
- MySQL 8.0
- MySQL Workbench
- SQL

## Advanced DBMS Concepts
- Joins and aggregate functions
- Views
- Stored procedures
- Triggers
- Indexing
- Window functions

## How to Run
1. Open MySQL Workbench and connect to your server.
2. Execute `student_performance.sql` to create the database and insert sample data.
3. Execute `student_performance_v2.sql` to add advanced features.
4. Execute `student_demo.sql` to generate analytics reports.

**Note:** Run the setup scripts only once. The demo queries can be executed repeatedly.

## Result
The system successfully generates academic rankings, grades, attendance-based alerts, and department-wise performance reports.
